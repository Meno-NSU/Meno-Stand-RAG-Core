## 5. Таблицы и сокращения в поиске Менона (без судьи)

**Таблицы.** Гипотеза: кросс-энкодер плохо оценивает чанки с markdown-таблицами. Проверка (`ragu-probe/table_render_probe.py`): каждый табличный чанк среди кандидатов Менона и каждый табличный чанк золотых страниц (582 вопроса; 4255 чанков) оценён тем же реранкером, что на проде (vLLM bge-reranker-v2-m3, :8002, обрезка 512), в исходном виде и со строками таблиц, переписанными в «столбец: значение; …». Золото в контексте при повторе отбора: 85.9% → 86.3% (+3 / −1), с табличными чанками золотых страниц как кандидатами — 86.4% (+4 / −1). Лучшая оценка золотого табличного чанка: медиана 0.422 → 0.444. Гипотеза не подтвердилась: в большинстве разобранных промахов реранкер ставит золотой таблице 0.87–0.97 («химия и биология» 0.947, «бакалавриат на ММФ» 0.972), но она уступает 8 слотов другим чанкам с ещё более высокими оценками.

**Сокращения.** У вопросов с сокращениями (146 из 582) золото в контексте 87.0%, без них 88.8% — системной проблемы нет; словарь сокращений, собранный по KB для RAGU, покрывает 129 из 164 сокращений в вопросах (ФИПЛ в нём есть). Случай «ФИПЛ» отдельный: кросс-энкодер ставит таблице экзаменов 0.0002 и в исходном, и в переписанном виде — здесь помог бы граф или словарь как расширение запроса, но таких вопросов единицы.

**Итог по поиску Менона.** Золотая страница среди 50 кандидатов в 94.7% вопросов и в контексте в 88.1%; оставшиеся промахи рассеяны (разные причины по несколько вопросов). Ни одна из проверенных правок поиска — свободные слоты, граф как навигатор, переписанные таблицы — не даёт больше нескольких вопросов из 582, а более полный контекст правильность ответов не поднимает (разделы 5, 9). Ресурс улучшения — в правилах ответа на типы вопросов и в эталонах, а не в поиске.

## 6. Иерархический отбор решающей моделью, как в DecisionRAG (без судьи, gemma на A6000 прода)

Статья: «Retriever-Free Retrieval: Navigating Documents with Decision Models» (arXiv 2610.35868). Решающая модель спускается по дереву (разделы → страницы → фрагменты) и для каждого варианта в общем списке оценивает «да / нет» по вероятностям за один токен; у авторов это их модель Jev или обученные Qwen3 со шкалой оценки. Мы проверили формат с непереобученными gemma-4-12B-it и Qwen3.5-9B (на A6000 прода на месте meno-lite, 14.11 с 14:42 UTC). Ответы gemma насыщены (вероятности 1.0 / 0.0), поэтому порядок — по логарифму отношения шансов «Да» / «Нет» из logprobs; оценка фрагмента = его шансы × шансы его страницы, как у авторов. Иерархия: 184 843 страницы KB v3.8 → 1000 кластеров k-means по средним векторам FRIDA страниц (описание кластера — заголовки типичных страниц); страница = заголовок + LLM-аннотация; фрагменты — текст чанков. Скрипты: `~/meno-v2/a6000/hier_build.py`, `hier_probe_a.py`, `hier_probe_b.py`.

**A: поверх кандидатов Менона** (582 вопроса с золотой страницей; до 25 страниц из 50 кандидатов Менона → 5 лучших страниц → 8 фрагментов):

| | Золотая страница |
|---|---:|
| среди 25 страниц-кандидатов | 93.6% |
| в 5 первых страницах по порядку Менона (кросс-энкодер) | 87.6% |
| в 5 лучших страницах по решениям gemma-4-12B | 76.3% |
| в 5 лучших страницах по решениям Qwen3.5-9B | 77.0% |
| в контексте Менона (8 чанков) | 87.8% |
| в 8 фрагментах по решениям gemma-4-12B | 74.9% (+19 / −94 к Менону) |
| в 8 фрагментах по решениям Qwen3.5-9B | 73.5% (+20 / −103 к Менону) |

Qwen3.5-9B отвечает менее категорично, чем gemma (P(«Да») ≈ 0.98 вместо 1.0), но выбирает так же: решения по заголовку и аннотации страницы проигрывают кросс-энкодеру по тексту чанков у обеих моделей.

**B: без поиска, по всему дереву** (пилот на 3 вопросах, где золотой страницы нет даже среди 50 кандидатов Менона; 10 кластеров из 1000 → 10 страниц → 8 фрагментов): золото пережило уровень кластеров в 3 из 3, уровень страниц — в 1 из 3, попало в итоговые 8 — в 1 из 3 (таблица экзаменов для «Какие экзамены нужно сдать на ФиПЛ»). Цена — 3.1–3.8 тыс. вызовов и ~7.5 мин на вопрос на A6000.

**Вывод.** Навигация по кластерам работает (нужный раздел находится), но решения непереобученной gemma о страницах по заголовку и аннотации заметно хуже кросс-энкодера по тексту чанков, а цена на порядки выше допустимой для прода. Этот формат имеет смысл только с обученной под него моделью-решателем (как у авторов: Qwen3 с головой «да/нет», обученный на парах «вопрос → страница»), и даже тогда предел правильности ответов — в генерации (разделы 9–11).
