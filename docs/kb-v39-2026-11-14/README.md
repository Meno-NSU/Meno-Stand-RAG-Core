## 1. Актуальность базы знаний v3.8 (14.11, сверка с живыми сайтами, только чтение)

Метаданные KB почти не хранят дату скачивания, поэтому свежесть проверена сверкой с сайтами (с прода, ≤3 параллельных запроса). Охват: документы KB из 10 ключевых тем (поступление, стоимость, общежития, стипендии, расписание, экзамены и аттестация, учебные правила, контакты, IT-сервисы, официальные документы), страницы и файлы на доменах *.nsu.ru. Мера для страниц — доля 5-словных фраз текста KB, найденных на живой странице (≥ 0.8 — совпадает); страницы с низкой долей перепроверены с определением кодировки (часть старых сайтов в windows-1251) и подсчётом текста без скриптов. Скрипты и результаты: `~/meno-v2/a6000/freshness_check.py`, `recheck_low.py`, `files_check.py`, `new_pages.py`; `~/meno-v2/a6000/freshness/*.jsonl`.

Затем: чанки, BM25, векторы FRIDA, новая коллекция Qdrant рядом с текущей, бенчмарк на стенде-копии со старой и новой базой, переключение — за владельцем, публикация на HF с происхождением.

## 2. База знаний v3.9 (14.11, по итогам раздела 1)

Собрана из v3.8 теми же инструментами (чанкер, BM25, CAG, FRIDA), только локальные модели; прод (коллекция `nsu_kb_v38`) не тронут. HF: датасет `Meno-NSU/NSU-Data-For-Meno`, **ветка `kb-v3.9`**, коммит `cd3b7eed` (364 файла, все сверены по sha256; main не менялся — `27afe45e`, v3.8; первая сборка — коммит `665e9ab7`, см. поправку ниже). Qdrant: коллекция `nsu_kb_v39` (631 882 вектора) рядом с `nsu_kb_v38`.

- Загрузка (Everest, CPU): 748 адресов по списку из раздела 1 — как в v3.7: robots.txt, 3 с между запросами, извлекатель `nsu_bitrix_v1` для www.nsu.ru, `generic_main_v1` для других сайтов, текстовый слой PDF.
- Изменившиеся страницы www.nsu.ru (тот же извлекатель, что у текста KB): **заменено 199** (`id` прежний, `edit_log.refetch_v39`, аннотация пересоздана gemma, промпт `kb39-summary-p1`); подтверждено без изменений 125.
- Страницы других сайтов, где текст KB делал другой инструмент: если старый текст ещё на странице — оставлен (новое извлечение тащит оформление: «Создал(а)…», «Нет меток»), иначе — пометка `live_changed_needs_review` (всего 86: 60 таких, 2 с ручной реконструкцией и 24 существующие страницы, текст которых стал намного короче текста KB — карточки сотрудников saes.nsu.ru показывают только имя и должность, расписания cag.nsu.ru — одну строку, списки преподавателей ГИ подгружаются скриптом): их нужно смотреть человеку или переизвлечь инструментом, которым они собирались.
- 4 документа, которых на сайте нет (3 — HTTP 404: два PDF www.nsu.ru и новость msec.nsu.ru; 1 — заглушка «раздел не найден»): текст сохранён, `source_status.state = removed_from_site`, вес −0,1. Поправка 15.11: в первой сборке (`665e9ab7`) удалёнными были помечены ещё 24 страницы с коротким текстом — они существуют, теперь это `live_changed_needs_review` без штрафа; чанки, векторы и коллекция `nsu_kb_v39` от этого не изменились (те же проиндексированные чанки). 1 224 записи с mmf-old.nsu.ru: `host_unreachable` (39 — `superseded_by` страница www.nsu.ru с тем же названием).

- Итог: записей 211 585 (+97), готовых для RAG 186 838; чанков 690 727, проиндексировано 631 882 (+331); векторы: 631 119 взяты из v3.8, 763 посчитаны на CPU (проверка — косинус ≥ 0,99994).
